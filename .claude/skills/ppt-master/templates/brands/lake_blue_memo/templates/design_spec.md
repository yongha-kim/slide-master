## V. Voice & Tone

- Formality: formal-institutional
- Person: none (third-person analytical voice)
- Emoji: forbidden
- Abbreviations: spell-out-first-use
- **Assertion titles**: every content-page title is a complete investment assertion ("The asset will reprice because capacity is scarce", not "Market Overview"), followed by a one-line subtitle defining scope and how to read the page; reading only the titles must tell the whole story
- **Number discipline**: every number carries a unit, point in time, and basis of measurement; estimates are labeled (illustrative / internal estimate); bare numbers are not allowed
- **Returns and valuation**: returns appear only as scenario ranges (downside / base / upside with probabilities or driver assumptions), never as a single-point IRR; every valuation conclusion carries a sensitivity table and a benchmark anchor (trading comparables, precedent transactions, or DCF cross-check)
- **Assumptions and risks**: assumptions are stated on the page whose conclusion depends on them; every risk is paired with its mitigation (Risk → Probability / Impact → Mitigation → Owner / Status)
- **Ending**: close on a decision or position (approve / reject / approve with conditions, or an allocation stance) plus an action list and timeline — never a thank-you page
- **Suggested sequence**: transaction decks — Executive Summary → Investment Highlights → Target / Market → Business Plan / Financial Diagnosis → Valuation and Returns → Risks and Mitigations → Decision Request; research / outlook decks — Core View → Evidence → Scenario Analysis → Allocation Recommendation
- **Source-fact boundary**: apply the sequence and the disciplines above only where the source material supplies the facts. When a required element is missing (no sensitivity data, no mitigation owner, no benchmark set), mark it as a gap in the outline for the user — never invent figures, scenarios, or mitigations to satisfy the format
